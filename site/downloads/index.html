phonorheos

foh · noh · REE · ohss

A desktop app for macOS, Linux and Windows that speaks the text other apps send it. One queue, so that two apps never talk over each other. The voice is Kokoro, made on your own machine; after the first start it needs no network.

Free and open source under AGPL-3.0-or-later; a commercial licence is available. See all releases.

Any app can speak.

Programs send text over a small HTTP interface on the machine, or from the command line with phonorheos say, and hear back when it has been spoken.

One voice at a time.

Text from every app waits in one queue. Any item can be withdrawn, and Stop silences everything at once.

Your words, said your way.

28 English voices, a speed, and a word list for the names the voice gets wrong.

Installing

macOS 15 or later

Open the .dmg and drag phonorheos to Applications. It is signed and notarised.

Ubuntu 24.04 or later

Install the package with sudo apt install ./phonorheos-*.deb; it adds the app and the phonorheos command.

Other Linux

Make the AppImage executable with chmod +x and open it. Nothing is installed.

Windows 11

Run the setup.exe; it asks for an administrator and adds the phonorheos command. It is not signed, so Windows warns about it, and where Smart App Control is on it refuses it outright; the manual explains. Not yet tried on a Windows desktop.

The first start downloads the voice, about 330 MB, with its progress shown in the window. The app itself is large because it carries its own Python and PyTorch.

The user manual covers the window, voices and speed, the word list, other machines on your network, the command, and what to do when something goes wrong.
